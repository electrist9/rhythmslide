# RhythmSlide

音楽のリズム（BPM・ビート）に同期して、写真スライドショーを **リアルタイム表示** する Windows デスクトップアプリです。
MP4 などの書き出しは行わず、その場で再生・プレゼン表示します。

## 主な機能

- **写真の取り込み**: 指定フォルダを再帰的にスキャンし、EXIF 撮影日時の順に並べます（ junction/シンボリックリンクのループ検出、アクセス不能フォルダはスキップ）。
- **リズム解析**: 音声から BPM・ビート位置・信頼度・エネルギー曲線を推定し、キャッシュします（同じ音声は 2 回目以降ほぼ即時）。音声ファイルだけでなく動画ファイルも選択でき、その場合は音声トラックのみを使用します。
- **自動レイアウト**: 既定では半拍（単位=0.5拍＝8分音符）で写真を切り替えます。4つ打ちなら小節ごとに8回切り替わります。写真がスロットより多ければ間引き、少なければ写真を循環させて毎ビート切り替えます。低信頼度や音声なしは固定間隔（既定1.75秒/枚、1枚ずつ）にフォールバックします。単位ビート（半拍/1/2/4/8/16拍・自動）は編集メニューで変更できます。
- **画像順のランダム化**: 編集メニューの「再生のたびに画像順をランダム化」を有効にすると、再生・最初から再生・プレゼン開始のたびに写真の表示順がシャッフルされます（既定は無効＝読み込み順）。一時停止からの再開では並び変わりません。手動ロックした写真は配置が優先されます。
- **トランジットのランダム化**: 編集メニューの「切り替えごとにトランジットをランダム化」を有効にすると、画像の切り替えごとにトランジット（crossfade・ワイプ・スライド・fade・zoom）がランダムに選ばれます（既定は無効＝「既定のトランジション」設定に従う）。ランダム選択は「なし（none）」を除く効果から選ぶので、毎回必ず遷移が付きます。写真ごとに個別指定したトランジットがあれば、それがランダム選択より優先されます。ON にした時点で再レイアウトされ、タイムラインに実際の遷移が反映されます。
- **描画FPS（トランジットの滑らかさ）**: 編集メニューの「描画FPS」で **30 / 60 / 144 FPS** を選べます（既定は **60**）。これはプレビュー・プレゼンの再描画と音声クロック取得の間隔を決める値で、遷移の滑らかさはこの FPS が上限になります（144Hz モンターでもアプリ側の描画率が低いと滑らかになりません）。144Hz 環境で遷移をなめらかにしたい場合は **144 FPS** を選ぶと、100ms の遷移でも約14フレームで描画されます。高い FPS ほど画像の毎フレーム縮小で CPU 負荷が増えるため、不要なら 60 のままが安全です。なお遷移時間はスライド1枚の表示長の **40%** を上限とします（短いスロットで指定 ms が極端に縮まないよう緩和済み）。
- **余白の支配色化**: 画像はアスペクト比を保って画面内に収める（contain）ため縦横に余白が出ます。編集メニューの「余白を画像の支配色にする」を有効にすると、その余白が黒などの固定背景色ではなく、画像自体の支配色（色を量子化したヒストグラムの最頻色）で塗られます（既定は無効＝背景色で一律）。
- **FunScript 対応**: `.funscript`（JSON）を読み込むと、音声解析のビートではなくその切替時刻で画像を切り替えます。ファイル内の `actions`（`at`=ミリ秒, `pos`=位置）から切替点を選ぶルールは「ファイル > FunScript 切替ルール…」で変えられます（既定は **上昇のみ** ＝ **1つ前の `pos` を引いた値が 0 より大きい** `at` を切替点にする従来動作）。選べるルールは次の3つです。①**上昇のみ**: `pos` が上昇した瞬間に切替。②**局所極値（ピーク）**: `pos` が切り返す頂点（上昇頂点・下降頂点の両方）で切替（切替が増える）。③**累積移動距離**: `|Δpos|` を積算し、合計が指定ステップに達するたびに切替（揺れても規則的に切替）。いずれも「**振幅しきい値**」で微小な動きを無視できます。音声・動画ファイルを選択した際、**同じベースファイル名の `.funscript`** があれば自動で読み込みます。探索は ①音声・動画と同じフォルダ（隣接）→ ②「ファイル > FunScript 検索フォルダ…」で設定した**複数の検索フォルダ配下（再帰）** の順で行い、検索フォルダは設定に保存され次回以降も有効です。手動読み込みは「ファイル > FunScript を読み込む…」、解除は「FunScript を解除」（FunScript があれば単位ビート設定に関係なく切替点そのものが境界になります）。
- **画像の循環順（往復）**: 写真がスロットより少なく循環させるとき、「FunScript 切替ルール…」の「画像の循環順」を **往復（ping-pong）** にすると、0→1→2→…→最後→…→1→0→1… と順送りではなく往復で巡ります（既定は順送り）。
- **切替ルールのプリセット保存**: 「FunScript 切替ルール…」では、**モード・振幅しきい値・累積ステップ・循環順**の4項目を1組の**名前付きプリセット**として保存できます。ドロップダウンで選べば4項目へ自動反映、**保存**（同名は上書き）・**削除**が操作できます。プリセットはプロジェクトに依存せず、設定（`config.json`）とは**別のファイル（`funscript_presets.json`）**に保存され、再起動後も使えます（旧バージョンで `config.json` に保存されていたプリセットは、次回起動時に自動でこのファイルへ移行されます）。
- **プリセット選択の記憶**: 最後に選んだプリセットは `config.json` に記憶され、次回以降ダイアログを開くと**選択済みで表示**され、その4項目が反映されます。さらに起動時に、記憶したプリセットのルールが既定の切替ルールとして適用されます（その後にプロジェクト（`.rslide`）を読み込むと、プロジェクト側のルールが優先されます）。4項目を手動で編集すると選択は「カスタム」（未選択）に戻り、記憶も解除されます。
- **プレビュー再生**: 音声クロックに同期してトランジション・Ken Burns・アニメ GIF を描画します。
- **画像表示の全画面トグル（F11）**: **F11** で中央の画像表示（プレビュー）部分をボーダーレス全画面へ切り替えます。もう一度 **F11**（または **Esc**、全画面窓を閉じる）で通常のウィンドウ表示に戻ります。全画面中も音声クロックでの再生・切り替えはそのまま継続し、**Space**（再生/一時停止）と **Home**（最初から再生）も使えます。全画面中はプレゼン窓と同様に**マウスカーソルが隠れます**（プレゼン開始＝**F5** の独立フルスクリーン窓とは別機能）。
- **タイムライン編集**: スライドの移動・伸縮、トランジション種別、ロック、単位ビート・既定トランジションの変更。Undo/Redo 対応。再生中は再生位置が視界から外れないようタイムラインが自動で横スクロール追従します（再生位置が視界内に残っている限り手動スクロールを妨げません）。
- **プレゼン表示**: フルスクリーン、外部ディスプレイ選択、キー操作（←/→/Space/Esc）、ループ、スリープ抑制。
- **プロジェクト保存**: 設定と編集内容を `.rslide`（素の JSON・UTF-8）で保存・読み込み。旧形式（zlib 圧縮）のファイルもそのまま読み込めます。
- **外部制御（VLC 互換）**: ツールメニュー「外部制御（VLC 互換）…」で有効化すると、VLC と同じ HTTP インターフェースで MultiFunPlayer などの外部アプリから再生・停止・シーク・ファイル読み込みができます（既定は無効。ポート・待ち受けアドレス・パスワードを設定可。既定の待ち受けは `127.0.0.1` で、`0.0.0.0` にすると LAN 内の他端末からも制御可）。
- **多言語対応**: ツールメニュー「言語 / Language / 语言」で **日本語 / English / 中文** を選べます（既定は日本語。`language` 未設定の初回は OS のロケールから自動推定）。選択は `config.json` に保存され、**反映にはアプリの再起動が必要**です。言語メニュー自体は三言語併記なので、どの言語表示でも操作できます。

## 動作環境

- Windows 10/11（64bit）
- Python 3.12 以上（開発・検証は 3.15）
- 音声再生は PySide6 同梱の FFmpeg プラグインを利用します（MP3 / AAC / M4A / WAV / FLAC / OGG 対応）。動画ファイル（MP4 / MOV / MKV / WEBM など）も選択可能で、音声トラックのみを再生・解析に使用します（音声トラックが無い動画は選択時にエラー表示）。
- 音声デコードのフォールバックとして、システムに `ffmpeg` / `ffprobe` があれば利用します（任意）。

## インストール（開発用）

```powershell
# ワークスペース内に仮想環境を作成
python -m venv .venv
.venv\Scripts\activate

# 依存の導入
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt   # テスト用（pytest / pytest-qt）
```

## 起動

```powershell
python -m rhythmslide
```

コマンドライン引数に `.rslide` ファイルを渡すと、起動時に読み込みます。

```powershell
python -m rhythmslide project.rslide
```

## データ（キャッシュ・設定）の場所

ビート解析キャッシュ・サムネイルキャッシュ・設定（`config.json`）は、既定で
**アプリを格納するワークスペース（プロジェクト）フォルダ直下の `rhythmslide/data`** にだけ保存されます。
`%APPDATA%` / `%LOCALAPPDATA%` などユーザープロファイル下には保存しません。
環境変数 `RHYTHMSLIDE_DATA_DIR` で明示的に変更できます。
旧バージョンでワークスペース直下 `.rhythmslide_data` に保存されていたデータは、次回起動時に自動で `rhythmslide/data` へ引っ越されます（新場所に既に同名のファイルがある場合は上書きされません）。
サムネイルキャッシュは 1 元画像=1 ファイルではなく、`thumbcache/thumbnails.db` の
**1 個の SQLite DB**（JPEG を BLOB 格納）に集約されています。

## 設定の記憶

アプリ終了時に次の編集メニューの設定を `config.json` に保存し、次回起動時に自動で反映します。

- 単位ビート
- 既定のトランジション
- 遷移時間(ms)
- 描画FPS
- 再生のたびに画像順をランダム化
- 切り替えごとにトランジットをランダム化
- 余白を画像の支配色にする

（前回選択したフォルダや外部制御の設定も同じ `config.json` に保存されます。）

## 言語（多言語対応）

UI 表示言語は **日本語（既定）/ English / 中文** から選べます。ツールメニューの
「言語 / Language / 语言」で選ぶと `config.json` の `language` に保存されます。
**反映にはアプリの再起動が必要**です（言語メニュー自体は三言語併記なので、どの言語表示でも切り替え操作ができます）。
`language` が未設定の初回起動時は OS のロケールから en / zh を推定し、いずれでもなければ日本語になります。

翻訳は Qt の標準機構（`tr()` → `.ts` → `.qm` + `QTranslator`）で実装しています。
翻訳ファイルは `rhythmslide/locale/rhythmslide_<lang>.qm`（編集用の元データは同じフォルダの `.ts`）に置き、
PyInstaller ビルド時は onedir で `_internal/locale/`、onefile で `_MEIPASS/locale/` へ同梱されます。
原文（日本語）は翻訳ファイル不要で、`language` が `ja` のときは翻訳をロードしません。
翻訳の更新手順は `pyside6-lupdate`（原文抽出）→ `.ts` を翻訳編集 → `pyside6-lrelease`（`.qm` 化）です。

## 外部制御（VLC 互換）

ツールメニューの「外部制御（VLC 互換）…」で、外部アプリからの操作を受け付ける HTTP サーバを
On/Off できます。**既定は無効**です。有効にすると VLC の mod_http と同じ形式で次の API を応答します。

- `GET /requests/status.json` … 再生状態（`apiversion`・`state`・`currentplid`・`time`/`length`（秒）など）。
  `?command=<コマンド>` を付けると操作も実行します。
- `GET /requests/playlist.json` … 読み込み中の音声・動画（現在の項目の `uri`）。

MultiFunPlayer の `VlcMediaSource` が実際に使うコマンドのみを実装しています:
`pl_forceresume` / `pl_forcepause` / `pl_stop` / `seek&val=<秒>` / `change_rate&val=<倍率>` /
`in_play&input=<URLエンコードしたパス>`（ファイル読み込み。空なら停止）。

設定項目（`config.json` に保存、次回起動時も有効）:

- **ポート**: 既定 `8080`（VLC と同じ）。
- **待ち受けアドレス**: 既定 `127.0.0.1`（この PC 内のみ）。`0.0.0.0` などにすると LAN 内の他端末からも接続できます。
- **パスワード**: 既定は空欄＝**認証なし**。設定すると Basic 認証（ユーザー名は空）を要求します。

既定の待ち受けアドレスは **127.0.0.1（ループバック）** なので、この PC 内からのみ接続でき、外部の PC からは接続できません。LAN 内の他端末から制御したい場合は、待ち受けアドレスを `0.0.0.0`（全インターフェース）や自ホストの LAN IP に設定してください。その場合は **パスワードを設定し、LAN のセキュリティが確保されている前提**でご利用ください（認証なしで `0.0.0.0` にすると、LAN 内の誰でも操作できます）。
MultiFunPlayer 側は接続先に `127.0.0.1:8080`（同一 PC 内の場合。LAN 越しならサーバ PC の IP とポート）、パスワードを同じ値に設定します。

## 実装上の注意（計画書からの変更点）

- **リズム解析**: 計画書は librosa を想定していましたが、検証環境の Python 3.15 では librosa/numba が導入できなかったため、**純 numpy で同一アルゴリズム**（スペクトルフラックス onset → 自己相関でテンポ → ビートグリッド → 信頼度 → RMS エネルギー）を再実装しています。
- **描画**: 計画書は QGraphicsView を想定していましたが、音声クロック駆動の正確なトランジション/Ken Burns 制御のため、**カスタム QWidget の paintEvent レンダラ**（`SlideRenderer`）を採用しました。同期精度は ±30ms 級を想定し、約 33ms の描画タイマで音声位置をポーリングします。
